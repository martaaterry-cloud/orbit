# Orbit — GitHub Pages

## Publicarla gratis y sin anuncios

1. Entra en https://github.com e inicia sesión.
2. Pulsa **New repository**.
3. Ponle de nombre, por ejemplo: `orbit`.
4. Déjalo como **Public**.
5. Pulsa **Create repository**.
6. Dentro del repositorio, pulsa **Add file → Upload files**.
7. Sube TODOS los archivos de esta carpeta:
   - index.html
   - manifest-v2.webmanifest
   - orbit-icon-v2-180.png
   - orbit-icon-v2-192.png
   - orbit-icon-v2-512.png
   - orbit-icon-v2-1024.png
   - y los demás iconos incluidos
8. Pulsa **Commit changes**.
9. Ve a **Settings → Pages**.
10. En **Build and deployment / Source**, selecciona:
    - **Deploy from a branch**
    - Branch: `main`
    - Folder: `/ (root)`
11. Pulsa **Save**.
12. Espera 1–3 minutos.

Tu web quedará normalmente en:
`https://TU-USUARIO.github.io/orbit/`

## En iPhone

1. Abre esa URL en Safari.
2. Pulsa Compartir.
3. Pulsa **Añadir a pantalla de inicio**.
4. Si ya tenías una Orbit anterior, bórrala primero para que iOS vuelva a leer el icono.

## Privacidad

La web será públicamente accesible por URL, pero tus puntos, impulsos, notas y premios
se guardan en `localStorage` del navegador de tu dispositivo. No se suben a GitHub.
